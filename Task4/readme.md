# Примечаний

1. API-Gateway(NGinx) для масштабирования и балансировки нагрузки между экземплярами приложения.
2. SSE в core-app в веб-приложения для получения текущих предложений от страховых по мере получания ответов соответствуюих информационных систем.
3. Асинхронное взаимодействие core-app и osago-aggregator.

### Патерны:

1. Использование патерна Transactional Outbox реализацией внутри сервисов:
 - для core-app при оформлении страховки и публикация события для взаиморасчётов,
 - для ins-product-aggregator при сохранении данные о доступных продуктах в свою БД перед публикацией событий,
 - для osago-aggregator при сохранении предложения по заявке в свою БД перед публикацией событий.

2. Паттерны отказоустойчивости для сервисов взаимодействия со страховыми компаниями:
 - Timeout - ограничения времени отдельных вызовов,
 - Retry - при кратковременных ошибках,
 - Circuit Breaker  - для отключения сбойных страховых информационных систем. 

3. Паттерны отказоустойчивости для сервиса взаимодействия с системами партнёров:
 - Rate Limiter - 20 RPS, для устранения проблем со злоупотреблениями и ошибками со стороны информационных систем партнёров.
